開発者が実際に使う小さなツール。

テストファイル、JSON整形、Markdown編集まで、すべてブラウザ内で完結します。どこにもアップロードされず、透かしもなく、アカウント作成も不要です。

開発者ツール

テストファイルジェネレーター

PDF、ZIP、JPG、PNG、GIF、TXT、BINなど、正確なサイズと拡張子のファイルを生成します。アップロード制限や品質チェックのテストに。

ツールを開く

JSONフォーマッタ

入力しながらJSONを整形・検証・圧縮し、エラーの正確な位置と折りたたみ可能なツリー表示を提供します。

ツールを開く

Markdownエディタ

左右に並んだリアルタイムプレビュー付きの2ペインMarkdownエディタ。HTMLまたはMarkdownで書き出せます。

ツールを開く

UUIDジェネレーター

ランダムなUUID v4識別子をブラウザ内でまとめて一括生成できます。大文字表記への変換やハイフンなし表記のオプションを選択でき、1件だけまたは全件を一度にコピーすることも可能です。

ツールを開く

Base64 エンコード／デコード

ブラウザ内でテキストをBase64にエンコードしたり、デコードして元に戻したりできます。UTF-8のマルチバイト文字にも完全対応し、URLセーフな出力形式もオプションで選べます。

ツールを開く

ハッシュジェネレーター

任意のテキストの MD5、SHA-1、SHA-256、SHA-512 ハッシュを、入力と同時にブラウザ内だけで生成します。アップロードは一切行われません。

ツールを開く

タイムスタンプ変換ツール

Unixタイムスタンプと読みやすい日付表記の間をリアルタイムで双方向に変換できます。ローカルタイム、UTC協定世界時、標準のISO 8601形式のいずれの出力にも対応しています。

ツールを開く

JSON Diff

2つのJSONドキュメントを比較し、追加・削除・変更された箇所を正確にハイライト表示して確認できます。比較処理はすべてブラウザ内で完結し、内容がアップロードされることはありません。

ツールを開く

JWTデコーダー

ブラウザ内でJWTトークンのヘッダー部分とペイロード部分をデコードして中身を確認できます。有効期限や標準クレームの意味も併せて解説。署名の検証は行わず、トークンもアップロードされません。

ツールを開く

正規表現テストツール

サンプルテキストに対して正規表現をリアルタイムのマッチハイライト付きでブラウザ内でテスト。キャプチャグループとすべての一致を確認。アップロードなし。

ツールを開く

CSVからJSON

ブラウザ内でCSVファイルをJSON形式にリアルタイムで変換します。区切り文字を自動で検出し、1行目を自動的にヘッダー項目名として扱い、整形された出力を得られます。

ツールを開く

CSVビューア

CSVファイルをブラウザ内で編集可能な表としてそのまま表示・操作できます。セルの内容を編集したり、行や列を自由に追加したりして、最後にCSV形式として書き出せます。

ツールを開く

URLエンコード/デコードツール

URLまたはURLコンポーネントをブラウザ内でリアルタイムにエンコード・デコード（パーセントエンコーディング）。コンポーネントモードと完全URIモード対応。アップロードなし。

ツールを開く

HTMLエンティティエンコーダー/デコーダー

HTMLエンティティ（< > & など）をブラウザ内でリアルタイムにエスケープ・アンエスケープ。名前付きエンティティと数値エンティティに対応。アップロードなし。

ツールを開く

YAMLからJSONへの変換ツール

YAMLをJSONに、またはJSONをYAMLにブラウザ内でリアルタイム変換。マッピング、シーケンス、引用符付き文字列、コメントに対応。アップロードなし。

ツールを開く

Cron式パーサー

cron式を貼り付けるだけで、わかりやすい日本語の説明文と、次に実行される5回分のスケジュールプレビューがその場で得られます。解析処理はすべてブラウザ内だけで完結します。

ツールを開く

進数変換ツール

2進数、8進数、10進数、16進数の間でリアルタイムに数値を変換。2〜36の任意のカスタム進数にも対応。負の数や任意の大きさの数値も扱えます。

ツールを開く

テキスト差分チェッカー

2つのテキストブロックを行単位で比較し、変更箇所を正確に表示します。空白や大文字小文字の違いを無視するオプションもあり、差分結果はコピー可能。処理はすべてブラウザ内で完結します。

ツールを開く

CSS詳細度計算ツール

セレクタを貼り付けると、それぞれの詳細度を分解してカスケード順にランク付けして表示します。

ツールを開く

.gitignoreジェネレーター

スタックにチェックを入れるだけで、重複行のない結合済み.gitignoreが得られます。

ツールを開く

JSON Schemaジェネレーター

JSONサンプルを貼り付けると、その構造と型を記述するdraft-07 JSON Schemaが得られます。

ツールを開く

User-Agentパーサー

任意のUser-Agent文字列を貼り付けると、判別されたブラウザ、エンジン、OS、デバイスタイプが表示されます。

ツールを開く

URLパーサー

任意の完全なURLを貼り付けると、プロトコル、ホスト、ポート、パス、クエリ、ハッシュに分解して表示します。

ツールを開く

SVGオプティマイザー

コメント、メタデータ、エディタの不要な情報、余分な空白を除去します。ファイルサイズの減少をリアルタイムで確認できます。

ツールを開く

SVGからReactコンポーネントへ変換

SVGマークアップを貼り付けると、すぐにインポートできるReact関数コンポーネントが得られます。

ツールを開く

CSS変数抽出ツール

スタイルシートを貼り付けると、すべてのカスタムプロパティをプレフィックスごとにグループ化して抽出し、重複にはフラグを立てます。

ツールを開く

SVGスプライトジェネレーター

複数のSVGアイコンを、IDの衝突を防いだシンボルベースの1つのスプライトシートに結合します。
