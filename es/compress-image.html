norito / Comprimir a un tamaño

Comprimir imagen a un tamaño objetivo

Olvídate de adivinar con el control de calidad. Dile el tamaño que necesitas, digamos 100 KB, y encuentra la mejor calidad que encaja, manteniendo el ancho y alto originales de tu imagen por defecto.

Haz clic para elegir una imagen, arrástrala aquí o pégala con Ctrl+V

JPG, PNG, WebP. Se queda en tu dispositivo, no se sube nada.

Permitir redimensionar
Desactivado por defecto. Mantiene el ancho y alto originales. Actívalo para reducir también las dimensiones, para objetivos más pequeños que la calidad por sí sola no puede alcanzar.

Tu imagen comprimida aparecerá aquí una vez generada.

Para JPEG/WebP, busca por bisección la calidad al tamaño original de tu imagen. Si "Permitir redimensionar" está desactivado y la calidad por sí sola no puede alcanzar el objetivo, obtendrás el tamaño más pequeño posible sin cambiar las dimensiones. PNG no tiene pérdida, así que alcanzar un objetivo pequeño necesita el redimensionado activado. JPEG o WebP te acercarán mucho más a un objetivo pequeño a tamaño completo.
