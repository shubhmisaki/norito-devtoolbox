CSS पैटर्न जनरेटर

शुद्ध CSS ग्रेडिएंट से टाइल होने वाला बैकग्राउंड पैटर्न बनाएं, किसी इमेज फ़ाइल की ज़रूरत नहीं, और CSS कॉपी करें. 


          
        

      

    


    

      
यह कैसे काम करता है

      

        हर प्रीसेट एक या दो CSS linear-gradient() या radial-gradient()
        लेयर बनाता है, जिनमें हार्ड कलर स्टॉप होते हैं (उनके बीच कोई सॉफ़्ट ब्लेंड नहीं), और यही
        चीज़ स्मूद ग्रेडिएंट को एक शार्प रिपीटिंग शेप में बदल देती है. background-size
        को ठीक एक टाइल के डाइमेंशन पर सेट किया जाता है ताकि पैटर्न किनारों पर बिना किसी दिखने वाली
        सीम के रिपीट हो, और डॉट्स/ग्रिड पैटर्न अपनी background-position को भी ऑफ़सेट करते हैं ताकि
        शेप कोने पर कटी हुई नहीं बल्कि सेंटर में दिखें.
      

      

        सब कुछ जनरेट किया गया CSS है, जो प्रीव्यू बॉक्स की अपनी background स्टाइल पर
        लगाया जाता है. कुछ भी अपलोड नहीं होता, और कोई इमेज रिक्वेस्ट नहीं भेजी जाती.
      

    




    
सामान्य प्रश्न

    

      

        क्या यह किसी इमेज फ़ाइल का इस्तेमाल करता है?
        
नहीं, हर पैटर्न CSS ग्रेडिएंट को रिपीटिंग बैकग्राउंड के तौर पर लेयर करके बनाया जाता है, कोई इमेज रिक्वेस्ट बिल्कुल नहीं होती. इससे पैटर्न किसी भी ज़ूम लेवल और किसी भी एलिमेंट साइज़ पर शार्प बना रहता है, क्योंकि यह वेक्टर मैथ है, रास्टर टाइल नहीं.

      

      

        क्या पैटर्न सीमलेस टाइल होगा?
        
हां, background-size को ठीक एक रिपीट यूनिट पर सेट किया जाता है, इसलिए पैटर्न किसी भी एलिमेंट साइज़ पर किनारे से किनारे तक बिना किसी दिखने वाली सीम के रिपीट होता है.

      

      

        क्या यह कहीं भेजा जाता है?
        
नहीं, पैटर्न पूरी तरह आपके ब्राउज़र के CSS इंजन में जनरेट और प्रीव्यू होता है. कुछ भी अपलोड नहीं होता.
