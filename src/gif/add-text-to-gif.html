How it works

Each frame is decoded to a full image and shown as a thumbnail in the frame strip above, so you can see exactly what you're captioning (and drop a frame you don't want with × before applying text). Every caption gets a numbered handle on the live preview, drag it anywhere on the image instead of picking from a fixed list of positions. Your caption is drawn onto a copy of every frame in its active range (with an optional outline in any color and thickness, plus an optional background box for readability over busy backgrounds), and the frames are re-encoded into a new GIF. Because the text is drawn fresh on every frame rather than overlaid as a separate layer, the exported file is a normal, single-layer animated GIF that works anywhere GIFs do.

Use "+ Add another caption" for subtitle-style captions, each one gets its own text, position, style, and "show from frame / until frame" range, so you can caption different sections of a longer animation differently instead of one caption stuck on the whole thing. Multi-line text is supported in every caption, each line is measured and centered independently so longer captions wrap the way you'd expect.

Common questions

Does the text stay in place while the GIF animates?

Yes, within a caption's active frame range, the same position, size, and style is drawn onto every one of those frames, so it stays fixed on screen for as long as it's set to show.

Can I add more than one caption, like subtitles?

Yes, use "+ Add another caption" to add as many as you want, each with its own text, position, style, and "show from frame / until frame" range, so different captions can appear on different sections of the animation.

Can I use more than one line of text?

Yes, press Enter in the text box to start a new line, each line is centered independently within the caption block.

Is my GIF uploaded anywhere?

No, the caption is drawn and the GIF is re-encoded entirely in your browser.
