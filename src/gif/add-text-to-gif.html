Add Text to GIF

Caption an animated GIF with your own text, top, bottom, or center, then download.

Click to choose a GIF, or drag and drop it here.

How it works

Each frame is decoded to a full image, your caption is drawn onto a copy of every single frame at the same position and size (with an optional black outline for readability over busy backgrounds), and the frames are re-encoded into a new GIF. Because the text is drawn fresh on every frame rather than overlaid as a separate layer, the exported file is a normal, single-layer animated GIF that works anywhere GIFs do.

Multi-line text is supported, each line is measured and centered independently so longer captions wrap the way you'd expect.

Common questions

Does the text stay in place while the GIF animates?

Yes, the same caption at the same position and size is drawn onto every frame, so it stays fixed on screen the whole time the GIF plays.

Can I use more than one line of text?

Yes, press Enter in the text box to start a new line, each line is centered independently within the caption block.

Is my GIF uploaded anywhere?

No, the caption is drawn and the GIF is re-encoded entirely in your browser.
