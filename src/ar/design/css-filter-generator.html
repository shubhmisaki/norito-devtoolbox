مولّد فلاتر CSS

أفلت صورة (اختياري)، اسحب أشرطة التمرير، وانسخ قيمة filter بصيغة CSS.

انقر أو أفلت صورة لمعاينتها عليها، اختياري


          
        

      

    


    

      
كيف تعمل

      

        يرتبط كل شريط تمرير مباشرة بدالة CSS filter واحدة
        (blur()، وbrightness()، وcontrast()،
        وsaturate()، وgrayscale()، وsepia()،
        وhue-rotate()، وinvert()). تُحذف الدوال المتروكة عند
        قيمتها المحايدة من الناتج للحفاظ على بساطة كود CSS المنسوخ، وتُدمج البقية
        بمسافات، لأن CSS يُطبِّق دوال الفلترة المتسلسلة بالترتيب الذي كُتبت به. تُضبَط
        هذه السلسلة النصية بالضبط كنمط filter الخاص بصورة المعاينة، لذا
        فما تراه هو التأثير الحقيقي، لا محاكاة له.
      

      

        تُحمَّل صورتك كرابط كائن محلي (object URL) ولا تغادر علامة تبويب المتصفح أبدًا؛
        لا توجد خطوة رفع.
      

    




    
أسئلة شائعة

    

      

        هل يمكنني معاينة هذا على صورتي الخاصة؟
        
نعم، أفلت أي صورة وسيُحدِّث كل شريط تمرير المعاينة الحية فورًا. بدون صورة مرفوعة، تعاين أشرطة التمرير على تدرّج لوني بديل بدلًا من ذلك.

      

      

        هل يؤثر الفلتر على التخطيط؟
        
لا. فلتر CSS تأثير بصري بحت، لا يغيّر أبدًا حجم أو موضع صندوق العنصر، على عكس استبدال ملف الصورة الفعلي. هذا يجعله رخيصًا لتفعيله عند التمرير فوق العنصر (hover) أو عبر صنف، لأن شيئًا لا يُعاد رسمه (reflow).

      

      

        هل تُرفع صورتي إلى أي مكان؟
        
لا. تستخدم المعاينة محرك CSS الخاص بمتصفحك على رابط كائن محلي (object URL). لا شيء يُرفع.
