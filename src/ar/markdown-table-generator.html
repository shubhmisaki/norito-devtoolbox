مولّد جداول Markdown

الصق بيانات CSV أو TSV (من جدول بيانات أو ملف)، حدّد محاذاة الأعمدة، واحصل على صياغة جدول Markdown نظيفة بأسلوب GitHub.

كيف يعمل

      

        يُقسَّم الإدخال عند أيّ فاصل، الفاصلة أو المسافة الرأسية، يتكرر أكثر في السطر الأول، لذا فإن
        اللصق مباشرة من جدول بيانات (مفصول بمسافة رأسية) أو من ملف ‎.csv‎ (فاصلة) يعمل كلاهما دون
        الحاجة لتبديل إعداد. تُحشى القيم إلى أعرض خلية في كل عمود بحيث يكون الناتج مُحاذًى بدقة حتى في
        محرر نصوص عادي، وليس فقط عند العرض المُصيَّر، وتُرمِّز نقطتا صف الفاصل أيّ محاذاة اخترتها لكل
        عمود، وهي الصياغة القياسية بأسلوب GitHub التي يفهمها كل مُصيِّر: GitHub وGitLab ومعظم مولّدات
        المواقع الساكنة.
      

      

        يحدث التحليل والتنسيق داخل جافاسكريبت هذه الصفحة. لا شيء تلصقه يُرفع.
      

    





    
أسئلة شائعة

    

      

        هل تتعامل الأداة مع الفواصل والمسافات الرأسية معًا؟
        
نعم، الصق من جدول بيانات (مفصول بمسافة رأسية) أو من ملف CSV (مفصول بفواصل) وتكتشف الأداة تلقائيًا أي فاصل تستخدمه حسب الأكثر تكرارًا في السطر الأول.

      

      

        كيف تعمل محاذاة الأعمدة؟
        
اختر يسارًا أو وسطًا أو يمينًا لكل عمود، ويحصل صف الفاصل تحت الرأس على نقطتين في المكان الصحيح (:--- لليسار، :---: للوسط، ---: لليمين)، وهي بالضبط الطريقة التي تُشير بها صياغة Markdown بأسلوب GitHub إلى المحاذاة للمُصيِّرات.

      

      

        هل يُرسل جدولي إلى أي مكان؟
        
لا، يُحلَّل الجدول ويُبنى بالكامل داخل متصفحك. لا شيء يُرفع.
