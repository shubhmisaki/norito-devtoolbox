Changelog

Everything that ships on norito, in order. New tools, new languages, redesigns, and fixes.

July 19, 2026

Homepage redesign

A cleaner, faster homepage: search is now the primary way in (press ⌘K anywhere), tool listings moved to a dedicated All tools page, and the whole site got richer cards, better typography, and this changelog.

July 17–18, 2026

PDF, SEO & Design tools in more languages

The full PDF suite is now available in Spanish, Chinese, Arabic, Hindi, Russian, and Japanese. The SEO and Design suites followed in five of those languages, with the rest on the way.

July 16, 2026

Russian and Japanese

norito now speaks six languages: Spanish, Chinese, Arabic, Hindi, Russian, and Japanese, with a language switcher on every translated page.

July 15, 2026

Faster everywhere, installable as an app

Core Web Vitals pass: faster first paint, no layout shift, async font loading. norito is now a Progressive Web App: install it and most tools keep working offline. Also new: 8 more tools, comparison pages, and a how it works page explaining the browser-only architecture.

July 14, 2026

21 new tools, two new categories

SEO and Design join the lineup: meta tags, sitemaps, UTM builder, gradients, shadows, favicons, contrast checking, and more. Category hub pages for every group.

July 13, 2026

The PDF suite

Eleven PDF tools in one day: merge, split, rotate, convert both ways, reorder pages, page numbers, watermarks, text extraction, compression, and signing. All client-side, powered by pdf-lib and pdf.js.

July 11, 2026

Dark mode, ⌘K search, and a real PNG encoder

Site-wide dark mode, command-palette search from any page, FAQ schema, and a rebuilt image compressor with true indexed-color PNG encoding (82–91% smaller on real photos).

July 10, 2026

Hello, world

norito launches: a small collection of browser-only utilities. Test file generator, image compressor, placeholder generator, and friends. No uploads, no accounts, no nonsense.
