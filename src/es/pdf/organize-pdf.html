Cómo funciona

Las miniaturas se generan a partir de tu PDF por completo en tu navegador. Haz clic en la X de una página para marcarla para eliminar, haz clic de nuevo para deshacerlo. Usa las flechas de subir y bajar para cambiar la posición de una página. Nada se aplica de forma definitiva hasta que haces clic en Guardar PDF.

¿Se suben mis archivos PDF a algún sitio?

No. Todo, incluidas las miniaturas de las páginas, se genera completamente dentro de tu navegador. Tus archivos nunca salen de tu dispositivo ni tocan un servidor.

¿Cómo elimino una página?

Haz clic en la X de la miniatura de una página para marcarla para eliminar; se atenúa para mostrar que no se incluirá. Haz clic de nuevo para deshacerlo.

¿Cómo reordeno las páginas?

Usa las flechas de subir y bajar debajo de cada miniatura para mover esa página antes o después. El PDF final sigue el orden que se muestra en pantalla.

¿Puedo eliminar todas las páginas?

No, un PDF necesita al menos una página, así que el botón Guardar se desactiva si todas las páginas están marcadas para eliminar.

¿Puedo organizar un PDF protegido con contraseña?

Todavía no. La herramienta no puede leer PDF protegidos con contraseña o cifrados y mostrará un error, quita la contraseña primero con un lector de PDF.
