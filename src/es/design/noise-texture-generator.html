Generador de Textura de Ruido

Genera una textura de grano con densidad, opacidad y color ajustables, luego descárgala o cópiala como CSS.

Grano monocromo

Cómo funciona

Se rellena píxel a píxel un canvas del tamaño de tile elegido: cada píxel tira sus propios dados contra el deslizador de densidad para decidir si recibe grano, y luego el alfa de color de ese grano se escala según el deslizador de opacidad. El modo monocromo usa un solo color de grano en todo el lienzo; desactivarlo aleatoriza también el brillo de cada grano, para un aspecto más texturizado y menos uniforme. La vista previa en mosaico de abajo repite el mismo canvas como fondo CSS para mostrar cómo se comporta a escala.

Ambas salidas, el PNG descargado y la data URI de "copiar como CSS", provienen directamente de este canvas vía toDataURL/toBlob, por completo en tu navegador. No se sube nada.

Preguntas frecuentes

¿El PNG descargado se repetirá sin costuras?

Es ruido aleatorio píxel a píxel en lugar de un patrón repetitivo, así que usado como un background-image pequeño y repetido tampoco tendrá costuras visibles, ya que cada píxel es aleatorio de forma independiente y no hay una estructura más grande que se rompa en el borde del tile.

¿Cuál es la diferencia entre la descarga PNG y la copia CSS?

Descargar te da un archivo .png real para referenciar desde una hoja de estilos o un <img>. "Copiar como CSS" en cambio incrusta la misma imagen como una data URI en base64 directamente dentro de una regla background-image, útil para un bloque CSS autocontenido sin ningún archivo separado que alojar.

¿Se envía esto a algún sitio?

No, la textura se genera píxel a píxel en un canvas en memoria dentro de tu navegador. No se sube nada.
