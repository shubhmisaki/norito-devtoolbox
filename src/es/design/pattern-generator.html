Generador de Patrones CSS

Construye un patrón de fondo repetible a partir de degradados CSS puros, sin necesidad de ningún archivo de imagen, y copia el CSS. 


          
        

      

    


    

      
Cómo funciona

      

        Cada preajuste construye una o dos capas linear-gradient() o
        radial-gradient() de CSS con paradas de color duras (sin mezcla suave entre
        ellas), que es lo que convierte un degradado suave en una forma repetitiva nítida. El
        background-size se fija exactamente a las dimensiones de un tile, así que el
        patrón se repite sin costura visible en los bordes, y los patrones de puntos/cuadrícula
        además desplazan su background-position para que las formas queden centradas en lugar de
        recortadas en la esquina.
      

      

        Todo es CSS generado, aplicado al propio estilo background del recuadro de
        vista previa. No se sube nada, y no se hace ninguna petición de imagen.
      

    




    
Preguntas frecuentes

    

      

        ¿Esto usa un archivo de imagen?
        
No, cada patrón se construye con degradados CSS superpuestos como un fondo repetido, sin ninguna petición de imagen. Eso mantiene el patrón nítido a cualquier nivel de zoom y cualquier tamaño de elemento, ya que es matemática vectorial, no un tile rasterizado.

      

      

        ¿El patrón se repetirá sin costuras?
        
Sí, el background-size se fija exactamente a una unidad de repetición, así que el patrón se repite de borde a borde sin costura visible, en cualquier tamaño de elemento.

      

      

        ¿Se envía esto a algún sitio?
        
No, el patrón se genera y previsualiza por completo en el motor CSS de tu navegador. No se sube nada.
