Generador de Etiquetas hreflang

Añade el código de locale y la URL de cada versión de idioma, obtén el conjunto completo y recíproco de etiquetas hreflang para pegar en todas ellas.

Cómo funciona

      

        Por cada fila que añades, la herramienta genera una etiqueta
        <link rel="alternate" hreflang="..." href="..." />, y de forma crucial,
        genera el conjunto completo en cada generación, una etiqueta por idioma incluyendo
        una que se referencia a sí misma, porque eso es lo que exige la documentación de Google:
        las anotaciones hreflang solo cuentan cuando son recíprocas, cada página del grupo enlaza a
        todas las demás páginas del grupo. Pega el mismo bloque de salida en el
        <head> de cada versión de idioma; no necesitas editar a mano qué etiqueta
        apunta "a sí misma" en cada página.
      

      

        Los códigos de locale no se validan contra una lista fija (BCP 47 admite muchas
        combinaciones como en, en-US, pt-BR), así que
        verifica los tuyos con los valores admitidos por Google si tienes dudas. Nada de lo que
        introduces se sube.
      

    





    
Preguntas frecuentes

    

      

        ¿Las etiquetas hreflang deben ser recíprocas?
        
Sí, este es el error más común con hreflang: cada página del conjunto debe enlazar a todas las demás, incluida ella misma. Google ignora explícitamente las anotaciones hreflang que no están confirmadas por un enlace de vuelta correspondiente. Esta herramienta siempre genera el conjunto completo en cada generación, incluyendo una etiqueta que se referencia a sí misma, para que puedas pegar el mismo bloque en cada versión de idioma.

      

      

        ¿Para qué sirve x-default?
        
Le indica a los motores de búsqueda qué página mostrar a los visitantes cuyo idioma o región no coincide con ninguna de tus entradas hreflang específicas, normalmente tu versión por defecto o en inglés. Es opcional pero recomendado para cualquier sitio multilingüe.

      

      

        ¿Se envían mis datos a algún sitio?
        
No, las etiquetas se ensamblan por completo en tu navegador a partir de las filas que introduces. No se sube nada.
