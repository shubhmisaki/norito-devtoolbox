Analizador de URL

Pega cualquier URL completa y mira su protocolo, host, puerto, ruta, parámetros de consulta y hash desglosados.

Cómo funciona

Esto se ejecuta por completo sobre la API URL nativa del navegador, el mismo analizador que usa tu navegador para navegar un enlace, así que el desglose es autoritativo en lugar de una aproximación con una expresión regular hecha a mano. Los parámetros de consulta provienen de URLSearchParams, que gestiona correctamente la decodificación por porcentaje y las claves repetidas.

Nada aquí obtiene la URL, solo analiza el texto que escribiste. No se hace ninguna solicitud de red, y ninguna parte de la URL sale de tu navegador.

Preguntas frecuentes

¿Cómo se tratan los parámetros de consulta?

Cada par clave=valor después del ? se decodifica y se lista por separado, incluidas las claves repetidas (como ?tag=a&tag=b), que aparecen como varias filas para que nada se colapse silenciosamente.

¿Funciona con URLs relativas?

No, se requiere una URL completa con protocolo, ya que la propia API URL del navegador (que esta herramienta usa directamente) necesita una base para resolver las relativas.

¿Se envía la URL a algún sitio?

No. El análisis usa la API URL integrada del navegador, totalmente del lado del cliente. No se sube nada, y no se hace ninguna solicitud a la propia URL.
