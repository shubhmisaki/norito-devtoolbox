Парсер URL

Вставьте любой полный URL и увидите его протокол, хост, порт, путь, параметры запроса и хеш, разложенные по полочкам.

Как это работает

Это работает полностью на встроенном в браузер API URL — том же самом парсере, которым браузер пользуется при переходе по ссылке, поэтому разбор точный, а не приблизительный результат самодельного регулярного выражения. Параметры запроса берутся из URLSearchParams, который корректно обрабатывает процентное декодирование и повторяющиеся ключи.

Ничего здесь не запрашивает сам URL — только разбирает введённый вами текст. Никаких сетевых запросов не выполняется, и ни одна часть URL не покидает ваш браузер.

Частые вопросы

Как обрабатываются параметры запроса?

Каждая пара key=value после ? декодируется и выводится отдельной строкой, включая повторяющиеся ключи (например, ?tag=a&tag=b) — они показываются несколькими строками, так что ничего не пропадает незаметно.

Работает ли это с относительными URL?

Нет, требуется полный URL с протоколом, поскольку встроенный в браузер парсер URL (которым этот инструмент пользуется напрямую) должен иметь базовый адрес, относительно которого разрешаются относительные ссылки.

Отправляется ли URL куда-либо?

Нет. Разбор выполняется полностью на стороне клиента с помощью встроенного в браузер API URL. Ничего не загружается на сервер, и никакого запроса к самому URL не выполняется.
