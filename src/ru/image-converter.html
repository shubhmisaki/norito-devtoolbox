Конвертер изображений

Конвертируйте изображение между JPG, PNG и WebP. Регулируемое качество для форматов с потерями, всё происходит на вашем устройстве.

JPG, PNG, WebP. Остаётся на вашем устройстве, ничего не загружается. Выберите несколько для пакетной конвертации.

Конвертированное изображение появится здесь после создания.

PNG без потерь (файлы больше, поддерживает прозрачность). JPEG и WebP с потерями, с ползунком качества (файлы меньше, без прозрачности для JPEG). WebP обычно превосходит JPEG при том же визуальном качестве, но JPEG обладает наибольшей совместимостью.

Как это работает

Ваше изображение загружается через локальный object URL (URL.createObjectURL), декодируется собственным декодером изображений браузера, отрисовывается на закадровом canvas в полном естественном разрешении и повторно кодируется с помощью canvas.toBlob в выбранном вами формате и качестве. Одна деталь обрабатывается за вас: у JPEG нет альфа-канала, поэтому перед отрисовкой canvas заполняется белым цветом, если целевой формат — JPEG. Без этого шага прозрачные области PNG получились бы чёрными. Ползунок качества применяется только к JPEG и WebP; кодирование PNG выполняется без потерь и игнорирует его.

Побочный эффект прохода через canvas, о котором стоит знать в любом случае: результат содержит только пиксели. EXIF-метаданные, модель камеры, временные метки и встроенные GPS-координаты из фотографий с телефона не сохраняются при повторном кодировании. Это делает данный конвертер незаметным выигрышем для конфиденциальности перед публичным распространением фото, но также важно учитывать, если метаданные вам действительно нужны (в этом случае сохраните оригинал). Браузеры применяют флаг ориентации EXIF при декодировании, поэтому снятые боком фотографии с телефона по-прежнему получаются правильно повёрнутыми.

Конвертация, пакетный режим и даже упаковка в .zip (собираемая побайтово в JavaScript) — всё это выполняется в вашем браузере. Откройте вкладку Network в DevTools и что-нибудь сконвертируйте: ни один запрос не передаёт изображение, поэтому ограничение размера файла зависит только от памяти вашего устройства.
