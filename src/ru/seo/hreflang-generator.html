Генератор тегов hreflang

Добавьте код локали и URL для каждой языковой версии — получите полный, взаимный набор тегов hreflang, который нужно вставить на каждую из них.

Как это работает

      

        Для каждой добавленной строки инструмент выводит один тег <link rel="alternate"
        hreflang="..." href="..." />, и, что особенно важно, при каждой генерации
        выводится весь набор целиком — по одному тегу на язык, включая тег, ссылающийся
        на саму страницу, — потому что именно этого требует документация Google: аннотации
        hreflang засчитываются только тогда, когда они взаимны, и каждая страница кластера
        ссылается на все остальные страницы кластера. Вставьте один и тот же блок вывода в
        <head> каждой языковой версии — вручную редактировать, какой тег
        указывает «на саму себя» на каждой странице, не нужно.
      

      

        Коды локалей не проверяются по фиксированному списку (BCP 47 допускает множество
        комбинаций вроде en, en-US, pt-BR), поэтому, если
        сомневаетесь, сверьтесь со списком поддерживаемых Google значений. Ничего из введённого
        вами не загружается.
      

    





    
Частые вопросы

    

      

        Должны ли теги hreflang быть взаимными?
        
Да, это самая распространённая ошибка при работе с hreflang: каждая страница набора должна ссылаться на все остальные страницы, включая саму себя. Google явно игнорирует аннотации hreflang, не подтверждённые встречной ссылкой. Этот инструмент всегда выводит полный набор при каждой генерации, включая тег, ссылающийся на саму страницу, поэтому вы можете вставлять один и тот же блок на каждую языковую версию.

      

      

        Для чего нужен x-default?
        
Он сообщает поисковым системам, какую страницу показывать посетителям, чей язык или регион не совпадает ни с одним из указанных вами hreflang-значений — обычно это версия по умолчанию или английская версия. Он необязателен, но рекомендуется для любого многоязычного сайта.

      

      

        Отправляются ли мои данные куда-либо?
        
Нет, теги полностью собираются в вашем браузере из введённых вами строк. Ничего не загружается.
