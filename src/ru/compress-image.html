Сжатие изображения до целевого размера

Забудьте про угадывание с ползунком качества. Укажите нужный размер, скажем 100 КБ, и инструмент найдёт лучшее подходящее качество, сохраняя исходные ширину и высоту изображения по умолчанию.

Нажмите, чтобы выбрать изображение, перетащите его сюда или вставьте через Ctrl+V

JPG, PNG, WebP. Остаётся на вашем устройстве, ничего не загружается.

Разрешить изменение размера
По умолчанию выключено. Сохраняет исходные ширину и высоту. Включите, чтобы также уменьшать размеры для маленьких целей, которых одно только качество достичь не может.

Ваше сжатое изображение появится здесь после генерации.

Для JPEG/WebP используется бисекция для подбора качества при исходном размере изображения. Если «Разрешить изменение размера» выключено, а одно только качество не может достичь цели, вы получите наименьший возможный размер без изменения размеров. PNG без потерь, поэтому для маленькой цели нужно включить изменение размера. JPEG или WebP приблизят вас к маленькой цели гораздо ближе при полном размере.
