Быстрее везде, устанавливается как приложение

Пройдены Core Web Vitals: более быстрая первая отрисовка, отсутствие сдвигов макета, асинхронная загрузка шрифтов. norito теперь Progressive Web App: установите его, и большинство инструментов продолжат работать офлайн. Также новое: ещё 8 инструментов, страницы сравнения и страница как это работает, объясняющая архитектуру «только в браузере».

Привет, мир

Запуск norito: небольшая коллекция инструментов, работающих только в браузере. Генератор тестовых файлов, компрессор изображений, генератор заполнителей и другие. Без загрузки файлов, без аккаунтов, без лишнего.
