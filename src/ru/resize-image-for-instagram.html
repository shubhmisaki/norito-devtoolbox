Изменить размер изображения для Instagram

Измените размер фото до квадратного формата поста Instagram 1080x1080 в один клик, прямо в браузере. Значения по умолчанию уже настроены — просто добавьте фото. Также подходит для портретных и альбомных постов.

JPG, PNG, WebP. Выберите несколько файлов для массового изменения размера. Остаётся на вашем устройстве, ничего не загружается.

Точные размеры растягивают или сжимают изображение до введённых вами ширины и высоты (зафиксируйте пропорции, чтобы избежать искажения). Процент масштабирует пропорционально от исходного размера. Ничего не загружается, изменение размера происходит на вашем устройстве с помощью API canvas.

Как это работает

Это изменение размера через canvas с уже заполненными числами Instagram. Ваше фото декодируется в браузере, отрисовывается на <canvas>, установленном на 1080x1080, с помощью drawImage(), которая ресемплирует пиксели встроенным фильтром сглаживания браузера, и повторно экспортируется через canvas.toBlob() (JPEG и WebP с качеством 0.92, PNG без потерь). Никакого приложения, никакой загрузки, а значения по умолчанию уже правильные для квадратного поста в ленте.

Почему именно 1080: Instagram хранит изображения ленты шириной до 1080 пикселей и повторно сжимает всё, что вы загружаете. Отправьте фото на 4000 пикселей — и Instagram сам уменьшит его, с настройками сжатия, которые вы не контролируете; отправьте ровно 1080 — и вы уже выполнили масштабирование с чистой ресемплировкой, оставив Instagram меньше возможностей испортить изображение. Три важных размера: 1080x1080 для квадрата, 1080x1350 для портрета (максимально допустимая высота и наибольшее пространство экрана в ленте), и 1080x608 для альбомной ориентации. Измените поле высоты, чтобы получить остальные два.

Одна вещь, за которой нужно следить: если ваш оригинал не квадратный, а вы принудительно задаёте точно 1080x1080 с отключённой фиксацией пропорций, изображение растягивается, а не обрезается, и это будет заметно на лицах. Правильный порядок — сначала обрезать до нужной формы (инструмент Обрезать изображение делает квадрат в один клик), затем изменить размер здесь с включённой фиксацией.

Всё происходит в вашей вкладке. Откройте панель Network в DevTools во время изменения размера: ваше фото никогда не загружается ни на этот сайт, ни куда-либо ещё, что нельзя сказать о большинстве инструментов «изменить размер для Instagram», которые незаметно пропускают ваше изображение туда и обратно через свои серверы.
