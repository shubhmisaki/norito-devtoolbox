Генератор таблиц Markdown

Вставьте данные CSV или TSV (из таблицы или файла), задайте выравнивание колонок — получите чистый синтаксис таблицы Markdown в стиле GitHub.

Первая строка — заголовок 

          
        

        

          
Предпросмотр рендера

          

        

      

    


    

      
Как это работает

      

        Входные данные разбиваются по тому разделителю — запятой или табуляции, — который чаще
        встречается в первой строке, поэтому вставка прямо из таблицы (с табуляцией) или из
        .csv-файла (с запятой) работает без переключателей в настройках. Значения дополняются
        пробелами до ширины самой широкой ячейки колонки, так что результат аккуратно выровнен
        и в обычном текстовом редакторе, а не только при рендере, а двоеточия в строке-разделителе
        кодируют выбранное вами выравнивание для каждой колонки — это стандартный синтаксис
        GitHub-flavored Markdown, который понимает любой рендерер: GitHub, GitLab, большинство
        генераторов статических сайтов.
      

      

        Разбор и форматирование происходят в JavaScript этой страницы. Ничего из вставленного вами
        не загружается.
      

    




    
Частые вопросы

    

      

        Понимает ли инструмент и запятые, и табуляцию?
        
Да, вставляйте данные из таблицы (с разделителями-табуляцией) или из CSV-файла (с запятыми) — инструмент сам определяет используемый разделитель по тому, какой из символов чаще встречается в первой строке.

      

      

        Как работает выравнивание колонок?
        
Выберите для каждой колонки выравнивание по левому краю, по центру или по правому краю — и в строке-разделителе под заголовком появятся двоеточия в нужных местах (:--- слева, :---: по центру, ---: справа) — именно так GitHub-flavored Markdown сообщает рендерерам о выравнивании.

      

      

        Отправляются ли мои данные куда-либо?
        
Нет, таблица разбирается и собирается полностью в вашем браузере. Ничего не загружается.
