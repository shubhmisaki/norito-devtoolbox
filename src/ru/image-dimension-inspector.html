Инспектор размеров изображения

Загрузите одно или несколько изображений и мгновенно узнайте ширину, высоту, соотношение сторон, мегапиксели и размер файла каждого из них.

Нажмите, чтобы выбрать изображения, или перетащите их сюда

Выберите несколько файлов для сравнения. Остаётся на вашем устройстве, ничего не загружается.

Как это работает

Каждый файл загружается как локальный object URL в элемент Image — именно так браузер считывает реальные размеры в пикселях из заголовка самого файла, а не из имени файла или какого-либо предположения. Соотношение сторон упрощается делением обоих измерений на их наибольший общий делитель (найденный с помощью алгоритма Евклида), а размер файла и формат берутся прямо из объекта файла, который уже есть у браузера.

Никакие данные изображения никуда не отправляются. Всё происходит локально, а object URL освобождаются сразу после того, как их размеры считаны.

Частые вопросы

Можно ли проверить сразу несколько изображений?

Да, выберите или перетащите сразу несколько файлов — каждый получит свою строку в таблице результатов, так что вы сможете сравнить размеры сразу для всей группы.

В каком виде показывается соотношение сторон?

В виде упрощённого соотношения (например, 16:9 или 4:3), полученного делением обоих измерений на их наибольший общий делитель, а также в виде десятичного значения для точного сравнения.

Загружается ли моё изображение куда-либо?

Нет. Файл читается локально и декодируется собственным движком изображений браузера. Ничего не загружается на сервер.
