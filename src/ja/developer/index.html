無料、登録不要|ブラウザ内で直接動作

開発者が実際に使う小さなツール。

テストファイル、JSON整形、Markdown編集まで、すべてブラウザ内で完結します。どこにもアップロードされず、透かしもなく、アカウント作成も不要です。

開発者ツール

テストファイルジェネレーター

PDF、ZIP、JPG、PNG、GIF、TXT、BINなど、正確なサイズと拡張子のファイルを生成します。アップロード制限や品質チェックのテストに。

ツールを開く

JSONフォーマッタ

入力しながらJSONを整形・検証・圧縮し、エラーの正確な位置と折りたたみ可能なツリー表示を提供します。

ツールを開く

Markdownエディタ

左右に並んだリアルタイムプレビュー付きの2ペインMarkdownエディタ。HTMLまたはMarkdownで書き出せます。

ツールを開く

CSS詳細度計算ツール

セレクタを貼り付けると、それぞれの詳細度を分解してカスケード順にランク付けして表示します。

ツールを開く

.gitignoreジェネレーター

スタックにチェックを入れるだけで、重複行のない結合済み.gitignoreが得られます。

ツールを開く

JSON Schemaジェネレーター

JSONサンプルを貼り付けると、その構造と型を記述するdraft-07 JSON Schemaが得られます。

ツールを開く

User-Agentパーサー

任意のUser-Agent文字列を貼り付けると、判別されたブラウザ、エンジン、OS、デバイスタイプが表示されます。

ツールを開く

URLパーサー

任意の完全なURLを貼り付けると、プロトコル、ホスト、ポート、パス、クエリ、ハッシュに分解して表示します。

ツールを開く

SVGオプティマイザー

コメント、メタデータ、エディタの不要な情報、余分な空白を除去します。ファイルサイズの減少をリアルタイムで確認できます。

ツールを開く

SVGからReactコンポーネントへ変換

SVGマークアップを貼り付けると、すぐにインポートできるReact関数コンポーネントが得られます。

ツールを開く

CSS変数抽出ツール

スタイルシートを貼り付けると、すべてのカスタムプロパティをプレフィックスごとにグループ化して抽出し、重複にはフラグを立てます。

ツールを開く

SVGスプライトジェネレーター

複数のSVGアイコンを、IDの衝突を防いだシンボルベースの1つのスプライトシートに結合します。

ツールを開く
