変更履歴

norito でリリースされたすべての内容を、時系列で。新しいツール、新しい言語、リデザイン、修正。

2026年8月13–14日

統一されたナビゲーション、フル幅表示

PDF、画像、開発、テキスト、ユーティリティ、SEO、Design、GIF——各カテゴリのドロップダウンはすべて、ページのコンテンツ幅に合わせたフル幅の1枚のパネルとして開くようになりました。各ツールはアイコン・タイトル・簡単な説明を備えた統一されたカードで表示されます。

2026年8月13日

アクセシビリティとユーザビリティの改善

コンテンツへスキップするリンクを追加し、ツールの完了・エラー時にスクリーンリーダーへ通知するようにしました。PDF圧縮など時間のかかる処理には進捗表示を追加し、画像系ツール8個にクリップボード貼り付けに対応、削除したGIFフレームは元に戻せるようになりました。

2026年8月12–13日

Norito GIF：6つの新ツール

GIF Maker、Video to GIF、GIF Compressor、GIF Resizer、GIF Splitter、Add Text to GIF——すべてブラウザ内で完結します。各フレームの実プレビューと編集可能な遅延時間、単なる再エンコードではなくgifsicleによる本格的な圧縮、長時間の変換をキャンセルできるボタンを備えています。現在は英語版のみで、翻訳は準備中です。

2026年8月10日

控えめな広告を追加

ツールページに少数の広告枠を追加しました。norito は引き続き無料で、アカウント登録や有料プランはありません——広告はホスティング費用に充てられます。

2026年8月3日

27個の新ツール

SVGオプティマイザー、SVG to React コンポーネント、gitignoreジェネレーター、JSON Schemaジェネレーター、User-AgentパーサーとURLパーサー、CSS詳細度・変数ツール（開発）。CSS clamp、easing、フィルター、パターン、ブロブ、ノイズテクスチャ、Tailwindシャドウの各ジェネレーター（Design）。HEIC・AVIFコンバーター、スクリーンショット注釈ツール、寸法インスペクター、SNS向け画像クロッパー（画像）。Markdownテーブルツールと不可視文字検出ツール（テキスト）。canonicalタグとhreflangジェネレーター（SEO）。そしてPDF比較ツール。すべて他の6言語にも翻訳済みです。

2026年8月2日

ソースコード全体を MIT ライセンスのもと GitHub で公開しました。あわせて、キーボードやスクリーンリーダー向けのラベルが不足していた箇所も修正しています。

2026年7月19日
