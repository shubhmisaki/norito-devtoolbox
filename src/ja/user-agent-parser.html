User-Agentパーサー

任意のUser-Agent文字列を貼り付けると、それが示すブラウザ、レンダリングエンジン、OS、デバイスタイプを表示します。初期値は自分自身のものです。

仕組み

文字列は、重複するブラウザを最もうまく区別できる順序で既知のトークンをスキャンされます。Chromiumベースのブラウザ（Edge、Opera、Brave、Vivaldi、Samsung Internet）はいずれも互換性のためにChrome/トークンを持っているため、先にそれぞれのより特定的なトークンをチェックしないと、すべて単なるChromeとして誤検出されてしまいます。OSは別のトークン群（Windows NT、Mac OS X、Android、iPhone OS/CPU OS、一般的なLinuxマーカー）から検出され、デバイスタイプはモバイル/タブレット固有のトークンの有無から判定されます。

すべての処理は、入力したテキスト、またはボックスを変更していない場合はnavigator.userAgentに対して、このページのJavaScriptで行われます。アップロードは一切行われません。

よくある質問

なぜデフォルトで自分自身のブラウザが表示されるのですか?

入力欄には最初から、今開いているこのページからローカルに読み取った、あなた自身のブラウザの文字列であるnavigator.userAgentが入力されています。他のUser-Agent文字列に上書きして貼り付ければ、そちらを解析できます。

すべてのブラウザとデバイスを完璧に検出できますか?

User-Agent文字列は本質的に雑然としています。多くのブラウザは互換性のために、ベースにしている他のブラウザのトークンを含んでいます（例えばEdgeとChromeはどちらも「Safari」と「KHTML, like Gecko」を含みます）。このツールは一般的なケースをカバーするパターンルールを使いますが、あまり見かけない文字列や偽装された文字列は誤って解釈されることがあります。

この文字列はどこかに送信されますか?

いいえ。解析は正規表現を使ってすべてブラウザ内で行われます。アップロードは一切行われません。
