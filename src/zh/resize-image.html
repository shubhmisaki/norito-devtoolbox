精确尺寸会按你输入的宽度和高度拉伸或缩小图片（锁定宽高比可避免变形）。百分比会按原始尺寸等比例缩放。不会上传任何内容，调整尺寸的操作使用 canvas API 在你的设备上完成。

工作原理

调整尺寸本身是一个浏览器原生操作：你的图片会被解码，系统会创建一个目标尺寸的 <canvas>，然后 drawImage() 在一次操作中把像素缩放绘制到该画布上。浏览器在此过程中会应用内置的平滑滤镜（一种双线性风格的重采样），对相邻像素取平均值，而不是简单地选取最近的一个像素，因此缩小后的照片看起来平滑而不会出现锯齿。之后，canvas 会根据所选的格式选项，通过 canvas.toBlob() 以 0.92 质量重新导出为 JPEG 或 WebP，或导出为无损 PNG。

这里有几个关于缩放的实用常识，也体现在这个工具的行为中。缩小正是调整尺寸真正出色的地方：把多个源像素平均合并到每个输出像素中，能让照片保持清晰。放大则无法凭空创造细节，同样的滤镜只是把已有的像素铺开，所以一旦放大超过大约 2 倍，画面就会开始变得模糊；如果你需要一个大尺寸版本，最好从你手头最大的原图开始处理。而平滑滤镜恰恰只在一种情况下不适用，那就是像素艺术（pixel art），这种场景其实需要生硬的最近邻边缘；而像这样的照片工具是为照片调校的。

百分比模式会根据原始尺寸计算目标尺寸，精确模式则直接采用你输入的数值，而锁定宽高比开关会让宽度和高度始终与原始比例保持一致，这样照片中的人物就不会被拉伸变形。尺寸每边上限为 20,000 像素，因为超过这个数值的画布可能会耗尽浏览器内存。批量模式会依次对每个文件运行相同的 canvas 处理流程，并将结果打包成一个同样在 JavaScript 中组装的 ZIP 文件。

由于整个处理流程——解码、绘制、重新编码——都在你的标签页内完成，你的照片永远不会离开你的电脑。你可以自己验证这一点：打开开发者工具，切换到 Network 标签页，然后调整一张图片的尺寸。你不会看到任何上传请求，而且即使离线，工具依然可以正常工作。
