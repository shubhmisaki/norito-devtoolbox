Markdown 表格格式化工具

粘贴一个竖线错位、间距不均的 Markdown 表格，得到一个整齐填充对齐的结果，内容和对齐方式都不会被改变。

工作原理

      

        每一行都会按未转义的竖线字符拆分为单元格（前面带 \ 的竖线会留在单元格内，不会触发拆分），每行开头和结尾可选的竖线在拆分前会先被去掉，这与 Markdown 本身的处理方式一致。第二行会与分隔符模式（:---、:---:、---: 或普通的 ---）进行比对；如果匹配，其中的冒号就决定各列的对齐方式；如果不匹配，工具会回退为普通的左对齐分隔行，并给出说明。之后每一列都会按其最宽的单元格重新测量并填充空格，因此无论是在渲染后的 HTML 中查看，还是在编辑器里看原始文本，竖线都能对齐。
      

      

        格式化完全在这个页面的 JavaScript 中随你的输入实时完成。你粘贴的内容不会被上传。
      

    




    
常见问题

    

      

        这和 Markdown 表格生成器有什么区别？
        
生成器是根据 CSV/TSV 数据从零构建一个新表格。这个工具则是接收一个已经是 Markdown 语法、但竖线和空格已经错位（手动编辑后很常见）的表格，重新填充对齐，且不改变任何单元格内容或已有的对齐标记。

      

      

        会保留列的对齐方式吗？
        
会。如果你的分隔行已经带有冒号（:--- 、:---: 或 ---:），会读取并保留该对齐方式。如果表格没有有效的分隔行，列会默认为左对齐，并附上一条说明，告知已重新生成了分隔行。

      

      

        我的表格会被发送到别的地方吗？
        
不会，解析和格式化完全在你的浏览器中完成。你粘贴的内容不会被上传。
