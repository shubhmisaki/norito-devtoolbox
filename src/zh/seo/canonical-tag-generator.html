输入一个网址，获取规范化的 <link rel="canonical"> 标签，可直接粘贴 到你页面的 <head> 中。

工作原理

      

        网址会通过浏览器原生的 URL API 解析，因此格式错误的输入会像浏览器本身
        一样被识别出来。开启去除跟踪参数选项后，一组固定的常见分析和广告参数
        （utm_source、utm_medium、utm_campaign、
        fbclid、gclid、msclkid 等）会被移除，其他查询
        参数则保持不变，因为只有你自己知道这些参数是否会真正改变页面的内容。
      

      

        这里不会请求这个网址，只会对你提供的文本进行格式化处理。不会发起任何网络请求。
      

    





    
常见问题

    

      

        Canonical 标签到底有什么作用？
        
它告诉搜索引擎，当相同内容可以通过多个网址访问时（比如带不带结尾斜杠，或者带有跟踪参数），哪一个才是“真正”的网址。这样搜索引擎就会把排名信号集中到这一个网址上，而不是分散在多个重复网址之间。

      

      

        为什么这个工具会去除查询参数？
        
默认情况下，它会移除常见的跟踪参数（utm_*、fbclid、gclid 等），因为 canonical 网址应该代表内容本身，而不是某人具体点击的那个链接。如果你的查询参数实际上会改变页面内容、需要保留，可以关闭这个选项。

      

      

        我的网址会被发送到别的地方吗？
        
不会，标签完全在你的浏览器中根据你输入的网址生成。不会上传任何内容，也不会对该网址本身发起任何请求。
