工作原理

      

        清理过程会移除 XML/DOCTYPE 声明、<!-- 注释 -->、
        编辑器专属的命名空间和元数据（Inkscape、Sketch、Illustrator 导出时留下的属性，
        以及设计工具遗留的 <metadata> 和 <title> 区块），
        并折叠标签之间多余的空白，这些都不会影响 SVG 的渲染效果。此外你还可以选择
        移除根元素上显式的 width/height 属性，让 SVG 纯粹依据其
        viewBox 缩放，这在响应式嵌入时很有用。
      

      

        整个过程都是对你提供的字符串进行文本处理，并使用浏览器自带的 DOM 解析器
        确保结果仍是合法的 XML。不会上传任何内容。
      

    





    
常见问题

    

      

        优化会改变 SVG 的显示效果吗？
        
不会，被移除的内容要么是不可见的元数据（注释、XML 声明、编辑器专属属性），要么是标签之间无意义的空白。渲染出来的图形完全一致，只是文件的字节大小变小了。

      

      

        为什么优化后我的 SVG 文件还是很大？
        
如果大部分体积来自真正的路径数据（复杂形状中的大量控制点）或内嵌的位图图片，仅靠清理是无法明显缩小的，因为这些数据属于可见内容的一部分。这个工具专注于安全的、无损的清理，而不是简化路径，后者可能会悄悄改变形状。

      

      

        我的 SVG 会被上传到别的地方吗？
        
不会。优化过程完全在你浏览器的 JavaScript 中进行，不会上传任何内容。
