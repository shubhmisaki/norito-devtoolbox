AVIF 转换器

把 JPG/PNG/WebP 转换成体积更小的 AVIF，或把 AVIF 转换回 JPG/PNG 以获得更好的兼容性。

点击选择一张图片，或将它拖放到这里

支持 JPG、PNG、WebP 或 AVIF。文件留在你的设备上。

转换后的图片会显示在这里。

工作原理

你的文件会被解码进一个 <img> 元素中（浏览器能原生显示 AVIF， 当前浏览器中解码支持已经很普遍），然后以完整分辨率绘制到 canvas 上。转换为 JPEG 或 PNG 使用 canvas 标准的、通用支持的编码器。转换为 AVIF 会调用 canvas.toBlob("image/avif")，目前 Chrome、Edge 和 Firefox 的最新版本 支持这个方法，但还不是所有浏览器都支持；这个工具会在提供该选项之前先检测支持情况， 如果你的浏览器无法编码它，会直接明确告知，而不是生成一个悄悄损坏的文件。

一切都发生在本页面自己的 canvas 中。不会上传任何内容，图片也不会离开你的 浏览器标签页。

常见问题

为什么要转换成 AVIF？

在同等视觉质量下，AVIF 通常比 JPEG 或 WebP 生成更小的文件，这也是它在网页图片中越来越常用的原因。代价是编码速度更慢，而且直到最近，在较旧的软件中支持度也不够普及。

如果我的浏览器不能编码 AVIF 怎么办？

目前所有主流现代浏览器都支持解码（查看）AVIF，但编码支持情况不一。如果你的浏览器无法输出 AVIF，这个工具会直接告诉你，而不是悄悄失败；无论如何，把 AVIF 解码为 JPG/PNG 在所有浏览器中都能正常使用。

我的图片会被上传到别的地方吗？

不会。两个方向的转换都使用你浏览器自带的图片解码器和 canvas 编码器完成，不会上传任何内容。
