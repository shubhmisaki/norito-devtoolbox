工作原理

针对每个预设，工具会计算出让图片完全覆盖目标宽高比、且四周不留空白所需的缩放比例——这与 CSS object-fit: cover 背后的数学原理相同，然后默认居中显示。缩放滑块在此基础上进一步放大，平移滑块则移动源图片中显示的窗口区域；两者都会作为源矩形参数传给 canvas.drawImage，因此裁剪结果始终基于你图片的完整分辨率渲染，而不是缩小后的预览图。

整个过程都在这个标签页的内存画布中完成。你的照片不会被上传，下载文件直接来自这块画布。

常见问题

裁剪框默认是怎么定位的？

默认居中，就像 CSS 的 object-fit: cover——预设的宽高比会被放大到刚好填满画框且不留空白，然后居中显示。用平移滑块调整图片中要保留在框内的部分，用缩放滑块裁得更紧一些。

输出的是每个平台建议的精确像素尺寸吗？

是的，每个预设下载时都会使用该平台当前建议的精确像素尺寸，而不只是正确的比例，所以你不需要再做一次调整尺寸的操作。

我的照片会被上传到别的地方吗？

不会。裁剪完全通过浏览器的 canvas API 在本地完成，不会上传任何内容。
