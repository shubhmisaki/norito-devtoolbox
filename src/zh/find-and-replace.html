查找和替换

在文档中查找和替换文本，支持可选的正则表达式、区分大小写和全字匹配，输入时实时更新。

工作原理

无论是纯文本查找还是正则表达式查找，每次搜索在底层都会被编译成一个 JavaScript RegExp 对象。在纯文本模式下，你的搜索词会先被转义（这样 .、(、$ 等字符会按字面意思匹配），「仅全字匹配」会用 \b 单词边界包裹该模式，大小写开关只是简单地添加或移除 i 标志。结果会在每次按键后重新渲染，匹配计数则来自在替换之前使用全局标志运行同一模式。无效的正则表达式输入不会清空你的文本，只会显示引擎的错误信息，并保持输出不变。

这里有一个大多数查找替换页面从未提及的功能：由于替换使用了 JavaScript 原生的 String.replace，反向引用在正则模式下是可用的。使用 $1、$2 表示捕获组，$& 表示整个匹配项。因此，查找 (\w+), (\w+) 并替换为 $2 $1，会在整个文件中把「Doe, Jane」变成「Jane Doe」，而 $$ 则可以在你需要时给出一个字面上的美元符号。

整个过程都在你机器上这个页面的 JavaScript 中运行。工作时打开开发者工具的 Network 标签页：没有任何请求携带你的文本，这正是为什么粘贴日志、配置文件，或任何你不想上传到随机网站的内容是安全的。
