工作原理

每个复选框都对应一个内置的小模板，覆盖该语言或工具典型的构建产物、依赖目录 和本地配置文件，与 GitHub 自己的 gitignore 模板集合所采用的模式相同。选中的模板 会拼接在各自的标注区块下，经过一轮去重处理，所以像 node_modules/ 这样的规则即使被两个所选模板同时包含，也只会出现一次， 而你的自定义规则会作为最后一个独立区块追加在末尾。

这个工具不会读取你的实际项目，它只是从内置在本页面 JavaScript 里的模板拼装文本。 不会上传任何内容。

常见问题

可以同时勾选多个模板吗？

可以。想勾多少个就勾多少个，比如同时勾选 Node、macOS 和 VS Code，它们会被合并成一个文件，去除重复的行，并且每个模板都保留在自己的标注区块下。

如果我需要的规则不在任何模板里怎么办？

使用下方的自定义规则输入框。你在那里输入的任何内容都会作为独立的区块追加到结果里，这样你就可以添加项目专属的路径，事后也不用再编辑生成的文件。

这会自动把文件应用到我的仓库吗？

不会，它只生成文本。你需要自己下载为 .gitignore 并放到仓库根目录，或者复制粘贴进去。
