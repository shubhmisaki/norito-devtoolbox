粘贴文本，找出其中隐藏的零宽字符和不可见 Unicode 字符，获得一份清理后的副本。

尚未发现隐形字符，粘贴文本即可开始扫描。

工作原理

文本中的每个字符都会与一份精心整理的清单逐一比对，涵盖零宽连接符与非连接符、零宽空格、字节顺序标记（BOM）、双向覆盖/嵌入控制符、软连字符，以及 Unicode “标签”字符（这个范围最初是给已废弃的语言标注功能用的，如今已成为在文本中隐藏不可见指令的一种已知手段，因为它们渲染出来什么都不显示）。每个命中项都会显示其码位、位置和简短标签，并以一个小的可见标记内联高亮，方便你准确看到它在文本中的位置。

“复制清理后的文本”会剥离所有被标记的字符并复制结果，正常的空白字符和可见字符则保持不变。整个过程都在本地完成，你粘贴的内容不会被上传。

常见问题

文本为什么会有隐形字符？

常见的无害原因：从 Word 或网页复制粘贴时，往往会带上零宽连接符或不换行空格。不太无害的原因：给 AI 生成文本加的隐藏水印，或者是为了绕过精确匹配过滤器和查重检测而故意插入的字符。

这里所说的“隐形”具体指什么？

零宽字符（连接符、非连接符、空格、BOM）、双向控制字符、大部分属于 Unicode “格式”和“控制”类别的字符，以及一份精心整理的、常被用于提示注入或规避过滤器的字符清单。

我的文本会被发送到别的地方吗？

不会，扫描完全在你的浏览器中通过 JavaScript 的 Unicode 感知字符串处理完成，不会上传任何内容。
