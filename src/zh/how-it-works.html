norito 的工作原理

每个工具都在你的浏览器中运行。无需上传，无需账号，没有人为限制。以下是具体原理，以及原因。

你上传的任何内容都不会离开你的设备

norito 上的每个工具，无论是合并 PDF、压缩图片，还是格式化 JSON，都完全在你的浏览器内使用 JavaScript 运行。当你把文件拖入某个工具时，它会被直接读入浏览器的内存并在那里处理。另一端并没有服务器在接收它，因为根本就没有上传这一步。

这之所以可行，是因为现代浏览器提供了强大的 API（File API、Canvas、Web Crypto 和 WebAssembly），这些能力过去需要服务器端处理才能实现。norito 建立在这些能力之上，再加上几个成熟的开源 PDF 处理库（pdf-lib 用于生成 PDF，pdf.js 用于渲染 PDF），它们同样完全在客户端运行。

无需账号，无需注册，无需邮箱

你现在就可以使用任何工具，无需创建账号或提供邮箱地址。没有什么需要记住，没有什么需要验证，也没有任何东西与你的身份绑定。

首次访问后即可离线使用

norito 是一个渐进式 Web 应用（PWA）。首次访问后，一个 Service Worker 会缓存网站的核心文件，因此大多数工具即使在没有网络连接的情况下也能继续使用，你还可以把 norito 安装到主屏幕或桌面，像原生应用一样使用。

norito 如何维持运营

norito 依靠展示广告（包括部分插页式广告）来维持运营，而不是订阅或付费墙。没有付费方案，没有功能限制，也没有为了推动你付费而设置的人为限制。关于我们的广告提供商会收集哪些数据（如果有的话）的完整细节，请见隐私政策。

我们能看到什么，不能看到什么

由于处理都在你的设备上进行，我们没有办法看到你处理的文件内容，也没有服务器日志记录它们——因为根本没有上传可供记录。和大多数网站一样，我们确实使用标准的、尊重隐私的分析工具来了解哪些工具被使用、网站表现如何，但那只是聚合的流量数据，而不是你文件的内容。

常见问题

norito 真的免费吗？

是的，每个工具都免费，没有每日限额，无需账号，也没有水印。网站依靠广告维持运营，而不是订阅制。

使用 norito 需要创建账号吗？

不需要。每个工具都可以立即使用，无需注册、登录或提供邮箱。

norito 能在没有网络连接的情况下使用吗？

可以，对大多数工具来说，只要你至少加载过一次 norito。它可以作为渐进式 Web 应用安装，并缓存核心文件以供离线使用。

文件大小有限制吗？

norito 本身没有设置任何人为限制。实际使用中，非常大的文件会受到你设备可用内存的限制，因为一切都在浏览器标签页中进行，而不是受 norito 设置的任何上限约束。

关闭标签页后我的文件会怎样？

什么都不会发生，因为它们从未被发送到任何地方。一旦你关闭或刷新标签页，浏览器内存中的内容就会直接消失。
