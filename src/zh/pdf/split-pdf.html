norito / 拆分 PDF

拆分 PDF 文件

从 PDF 中取出指定页面，或将其彻底拆开。输入你想要的页面，比如 1-3、5、8-10，然后下载结果。不会上传任何内容，一切都在你的设备上完成。

点击选择 PDF 文件，或将它拖放到这里

文件留在你的设备上，不会被上传。

拆分为独立文件
关闭时，你选择的页面会合并成一个 PDF。开启后，会为上面的每一组页面单独生成一个文件（如果留空，则是每页一个），打包为 .zip。
我的 PDF 文件会被上传吗？

不会。拆分操作完全在你的浏览器内通过 JavaScript 完成。你的文件不会离开设备，也不会接触任何服务器。

怎样只提取几页？

输入你想要的页码或范围，比如 1-3、7，然后点击拆分。它们会按顺序合并成一个新的 PDF。

可以把 PDF 拆分成每页一个文件吗？

可以。开启“拆分为独立文件”并将页码框留空，每一页都会作为单独的 PDF 打包进一个 .zip 文件下载。

可以一次提取多个不连续的范围吗？

可以。用英文逗号分隔它们，比如 1-3、5、8-10，再开启“拆分为独立文件”，就能把每组页面各自生成一个 PDF，打包进 .zip。

拆分会降低 PDF 的画质吗？

不会。页面会从源文件原样复制，没有重新渲染、重新压缩，也不会造成画质损失。

我可以拆分带密码保护的 PDF 吗？

目前还不行。工具无法读取带密码保护或加密的 PDF，会显示错误，请先用 PDF 阅读器移除密码。

工作原理

你输入的页码范围会先被解析，工具会在处理之前将每个数字与文档实际页数进行核对。随后完全在浏览器中运行的 pdf-lib 会把 PDF 的对象结构加载到内存中，并调用 copyPages() 提取所选页面，页面的字体、图片和图形会与存储时完全一致地一并复制。

“拆分为独立文件”开关会改变分组的处理方式。关闭时，你列出的所有页面会按你输入的顺序合并进一个文件。开启时，每个逗号分隔的组都会成为独立文件，打包进一个 .zip。

这一切都不会经过服务器。打开开发者工具，在拆分时观察网络面板：文件通过浏览器自带的 FileReader 读取，在内存中处理，下载来自本地生成的 blob。
