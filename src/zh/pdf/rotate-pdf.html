旋转 PDF 页面

修正横向或颠倒的页面。旋转整份文档，或只旋转你选中的页面，然后下载结果。不会上传任何内容，一切都在你的设备上完成。

点击选择 PDF 文件，或将它拖放到这里

文件留在你的设备上，不会被上传。

工作原理

PDF 里的每一页都有一个 /Rotate 字段，这是页面字典里的一个数字（0、90、180 或 270），用来告诉阅读器显示时应该把页面转向哪个方向。这个工具使用运行在你浏览器里的 pdf-lib 库，读取每个选中页面的这个数值，叠加上你选择的旋转角度，把结果重新限制在 0-359 的范围内，再写回去。仅此而已——页面的实际内容，包括文字、字体、图片和矢量图形，完全不会被触碰。

这一点其实很重要。有些转换工具"旋转" PDF 的方式，是把每一页渲染成图片，旋转这张图片，再重新拼装成文件。这种做法会破坏可选中的文字，让文件体积膨胀，画质也被锁死在渲染时的分辨率上。而只修改元数据的旋转正相反：完全无损、可逆（再转 270 度就能转回原样），即使是 500 页的文件也能瞬间完成，因为需要处理的工作量与页面内容无关。输出文件的大小几乎和输入文件完全一样。由于旋转是叠加在每一页当前数值之上的，一份已经是横放的扫描件，只会在此基础上再转动你要求的角度，而不会被重置。

和站内其他所有工具一样，文件始终留在这个标签页内。旋转时打开开发者工具的"网络"面板观察一下：不会有任何数据被传输，PDF 完全在内存中被修改，并从本地生成的 blob 中下载。

我的 PDF 文件会被上传吗？

不会。旋转操作完全在你的浏览器内通过 JavaScript 完成。你的文件不会离开设备，也不会接触任何服务器。

可以只旋转部分页面吗？

可以。输入你想要的页码或范围，比如 1-3、7，只有这些页面会被旋转。留空则旋转所有页面。

如果某一页已经是旋转过的呢？

你选择的旋转角度会叠加在每一页当前的方向上，而不是从零开始设置，所以已经是横向的页面会按预期再转 90、180 或 270 度，而不是被重置。

旋转会降低 PDF 的画质吗？

不会。旋转只是每一页的一项元数据改动，底层内容不会被重新渲染或重新压缩。

我可以旋转带密码保护的 PDF 吗？

目前还不行。工具无法读取带密码保护或加密的 PDF，会显示错误，请先用 PDF 阅读器移除密码。
