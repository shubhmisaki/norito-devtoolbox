为 PDF 添加水印

在每一页上盖上斜向文字水印，比如“机密”或“草稿”。选择文字、大小、颜色、透明度和角度。不会上传任何内容，一切都在你的设备上完成。

点击选择 PDF 文件，或将它拖放到这里

文件留在你的设备上，不会被上传。

机密

这是标准页面上的粗略效果，实际结果取决于你 PDF 的实际页面尺寸。

工作原理

水印会作为真实文字直接绘制在每一页上，居中、旋转并设为半透明，完全在你的浏览器中完成。它会成为页面本身的一部分，所以如果以后可能需要没有水印的版本，请保留一份原始文件。

我的 PDF 文件会被上传吗？

不会。水印完全在你的浏览器内通过 JavaScript 添加。你的文件不会离开设备，也不会接触任何服务器。

可以更改水印的角度和透明度吗？

可以。以度数设置旋转角度，以百分比设置不透明度，0% 是完全不可见，100% 是完全不透明。

水印会出现在每一页上吗？

是的，同一个水印会盖在文档的每一页上。

可以移除这个工具添加的水印吗？

无法用这个工具移除，水印会成为页面内容的一部分。如果以后可能需要没有水印的版本，请保留一份原始文件。

我可以为带密码保护的 PDF 添加水印吗？

目前还不行。工具无法读取带密码保护或加密的 PDF，会显示错误，请先用 PDF 阅读器移除密码。
