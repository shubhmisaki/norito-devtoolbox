合并 PDF 文件

按你选择的顺序，将多个 PDF 合并为一个文件。添加文件、排列顺序，然后下载合并后的 PDF。不会上传任何内容，一切都在你的设备上完成。

点击选择 PDF 文件，或将它们拖放到这里

添加两个或更多 PDF。文件留在你的设备上，不会被上传。

我的 PDF 文件会被上传吗？

不会。合并操作完全在你的浏览器内通过 JavaScript 完成。你的文件不会离开设备，也不会接触任何服务器。

我可以选择 PDF 合并的顺序吗？

可以。添加文件后，合并前可以用每一行的上移和下移按钮把它们排成你想要的顺序。

文件大小或 PDF 数量有限制吗？

工具本身没有硬性限制，实际的上限取决于你浏览器可用的内存，文件过大或过多可能会花费更长时间，在内存较小的设备上也可能吃力。

合并会降低 PDF 的画质吗？

不会。每个源文件的页面都会被原样复制，没有重新渲染、重新压缩，也不会造成画质损失。

我可以合并带密码保护的 PDF 吗？

目前还不行。工具无法读取带密码保护或加密的 PDF，会显示错误，请先用 PDF 阅读器移除密码。

工作原理

合并操作基于 pdf-lib 完成，这是一个直接在浏览器内存中操作文件内部对象结构的 PDF 库。点击合并后，工具会创建一个空白 PDF，按显示顺序遍历你的文件，对每个文件调用 copyPages()。这会复制每一页及其引用的所有内容：字体、图片、矢量图形和注释。

一个诚实的提醒：copyPages() 会复制页面树，但 PDF 的书签存在于文件的另一部分，不会被复制。页面的可见内容始终会完整保留。

你的文件不会离开这个标签页。你可以亲自验证：打开开发者工具的网络面板，添加你的 PDF 并合并。没有任何请求会把你的文档发送到任何地方。
