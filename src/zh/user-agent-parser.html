User-Agent 解析器

粘贴任意 User-Agent 字符串，查看它标识出的浏览器、渲染引擎、操作系统和设备类型。 默认显示你自己的信息。

工作原理

字符串会按照最能区分重叠浏览器的顺序扫描已知标记，因为基于 Chromium 的浏览器 （Edge、Opera、Brave、Vivaldi、三星浏览器）出于兼容性都带有 Chrome/ 标记，必须先检查它们各自更具体的标记，否则都会被误判为纯 Chrome。操作系统 通过另一组标记检测（Windows NT、Mac OS X、 Android、iPhone OS/CPU OS、常见的 Linux 标记），设备类型则取决于是否存在移动端或平板专属的标记。

一切都在本页面的 JavaScript 中，针对你提供的文本进行处理，如果你没有修改文本框， 则使用 navigator.userAgent。不会上传任何内容。

常见问题

为什么默认显示的是我自己的浏览器？

文本框会预先填入 navigator.userAgent，也就是你自己浏览器的字符串，直接从你正在访问的页面本地读取。把任意其他 User-Agent 字符串粘贴进去覆盖它，即可解析那一条。

它能完美识别每一种浏览器和设备吗？

User-Agent 字符串本身就很混乱，很多浏览器为了兼容性会携带它们所基于的其他浏览器的标记（例如 Edge 和 Chrome 都带有 "Safari" 和 "KHTML, like Gecko"）。这个工具使用覆盖常见情况的规则集，但生僻或伪造的字符串仍可能被误判。

这个字符串会被发送到别的地方吗？

不会。解析完全在你的浏览器中用正则表达式完成，不会上传任何内容。
