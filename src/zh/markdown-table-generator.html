工作原理

      

        输入内容会按第一行中出现次数更多的分隔符（逗号或制表符）拆分，因此无论是直接从表格软件粘贴（制表符分隔）还是来自 .csv 文件（逗号分隔），都无需切换任何设置即可正常工作。数值会按每列最宽的单元格填充空格，让输出在纯文本编辑器中也整齐对齐，不只是渲染后才好看；分隔行的冒号则会按你为每列选择的对齐方式编码，这是 GitHub、GitLab 以及大多数静态网站生成器都能识别的标准 GitHub 风格 Markdown 语法。
      

      

        解析和格式化都在这个页面的 JavaScript 中完成。你粘贴的内容不会被上传。
      

    





    
常见问题

    

      

        支持逗号和制表符两种分隔符吗？
        
支持，无论是从表格软件粘贴（制表符分隔）还是来自 CSV 文件（逗号分隔），工具都会根据第一行中出现更多次的分隔符自动判断你使用的是哪一种。

      

      

        列对齐是怎么实现的？
        
为每一列选择左对齐、居中或右对齐，表头下方的分隔行就会在相应位置加上冒号（左对齐是 :---，居中是 :---:，右对齐是 ---:），这正是 GitHub 风格 Markdown 向渲染器传达对齐方式的标准写法。

      

      

        我的数据会被发送到别的地方吗？
        
不会，表格完全在你的浏览器中解析和构建。不会上传任何内容。
