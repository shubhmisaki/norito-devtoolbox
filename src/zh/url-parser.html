URL 解析器

粘贴任意完整 URL，查看它被拆解出的协议、主机、端口、路径、查询参数和哈希片段。

工作原理

整个过程完全基于浏览器原生的 URL API，也就是浏览器导航到某个链接时 实际使用的同一个解析器，所以拆解结果是权威的，而不是手写正则表达式的近似结果。 查询参数来自 URLSearchParams，它能正确处理百分号解码和重复的 key。

这里不会请求该 URL，只是解析你输入的文本。不会发起任何网络请求，URL 的任何部分 都不会离开你的浏览器。

常见问题

查询参数是怎么处理的？

? 之后的每一个 key=value 对都会被解码并单独列出，包括重复出现的 key（比如 ?tag=a&tag=b），它们会以多行的形式展示，不会被悄悄合并。

支持相对 URL 吗？

不支持，必须输入包含协议的完整 URL，因为这个工具直接使用的浏览器自身的 URL 解析器需要一个基准地址才能解析相对路径。

URL 会被发送到别的地方吗？

不会。解析完全使用浏览器内置的 URL API，在客户端完成。不会上传任何内容，也不会对该 URL 本身发起任何请求。
