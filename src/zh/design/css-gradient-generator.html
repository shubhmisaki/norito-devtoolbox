常见问题

    

      

        可以添加两种以上的颜色吗？
        
可以，点击“添加色标”多少次都行。每个色标都有自己的颜色和位置百分比，因此你可以构建多色渐变，而不只是简单的双色渐变。

      

      

        线性和径向渐变有什么区别？
        
线性渐变沿着你设置的角度，以直线方式过渡。径向渐变则从一个中心点向外呈圆形扩散，角度设置对它不起作用。

      

      

        这些内容会被发送到别的地方吗？
        
不会。渐变完全通过你浏览器的 CSS 引擎构建和预览，不会上传任何内容。
