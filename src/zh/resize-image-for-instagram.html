为 Instagram 调整图片尺寸

一键将照片调整为 Instagram 的 1080x1080 方形帖子尺寸，全部在浏览器中完成。默认值已经设好，直接拖入照片即可。同样适用于竖版和横版帖子。

点击选择图片，或将其拖放到此处

支持 JPG、PNG、WebP。可多选批量调整尺寸。文件保留在你的设备上，不会上传任何内容。

锁定宽高比
更改宽度会自动更新高度以保持匹配，反之亦然。

生成后，调整尺寸后的图片会显示在这里。

精确尺寸会按你输入的宽度和高度拉伸或缩小图片（锁定宽高比可避免变形）。百分比会按原始尺寸等比例缩放。不会上传任何内容，调整尺寸的操作使用 canvas API 在你的设备上完成。

工作原理

这本质上是一次预先填好了 Instagram 参数的 canvas 尺寸调整。你的照片会在浏览器中解码，通过 drawImage() 绘制到一个设为 1080x1080 的 <canvas> 上，浏览器内置的平滑滤镜会对像素进行重采样，然后通过 canvas.toBlob() 重新导出（JPEG 和 WebP 质量为 0.92，PNG 无损）。不需要 App，不会上传，而且默认值本身就适合方形动态帖子。

为什么具体是 1080：Instagram 会将动态图片以最高 1080 像素宽存储，并对你上传的所有内容重新压缩。如果你发送一张 4000 像素的照片，Instagram 会自行缩小它，压缩设置由不得你控制；而如果你直接发送 1080 像素的照片，你已经用干净的重采样完成了缩放，留给 Instagram 处理和破坏的空间就更小。真正重要的三种尺寸是：1080x1080 用于方形，1080x1350 用于竖版（允许的最高高度，也是动态中占屏幕空间最多的），1080x608 用于横版。修改高度字段即可得到另外两种尺寸。

需要注意一点：如果你的原图不是正方形，而你在关闭宽高比锁定的情况下强制设为精确的 1080x1080，图片会被拉伸而不是裁剪，人脸会明显看出变形。正确的顺序是先裁剪成你想要的形状（裁剪图片工具一键即可裁成正方形），然后在这里开启锁定进行调整尺寸。

一切都在你的标签页内完成。调整尺寸时打开开发者工具的 Network 面板：你的照片从不会上传到这个网站或其他任何地方，而大多数「Instagram 尺寸调整」工具其实会悄悄把你的图片来回传输到它们的服务器，这一点与它们不同。
