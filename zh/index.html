为什么不直接上传到 Smallpdf?

Smallpdf、iLovePDF、TinyPNG、remove.bg——它们的工作方式都一样：文件上传到它们的服务器，处理后再传回来。norito 跳过了这一步。

文件不会离开这个标签页

每个工具都使用浏览器内置的 Canvas、File 和 WebAssembly API 运行。使用时打开 DevTools 的网络面板看看——没有任何请求发出，这不是空口承诺，十秒钟就能验证。

没有"升级才能处理大文件"

这里没有用量限制，没有水印，也没有付费门槛。每个工具只有一个版本，就是免费版。

离线也能用

把 norito 安装成应用后，大多数工具在没有网络的情况下也能继续使用——因为背后本来就没有服务器，谈不上"断开连接"。

norito 还不能做什么

norito 刻意保持精简。目前没有 PDF 转 Word/Excel/PowerPoint，没有 OCR，也没有音视频工具——这三类要在浏览器里做好都很难，通常需要一次性下载一个很大的组件，我们更愿意把已有的工具做快做精，而不是仓促上线一堆半成品。抠图功能是专门为人像照片调校的，不适合处理普通物体——用在产品图或风景照上效果会比较一般。

如果你需要的正是这些还没做的功能，告诉我们，需求越多就会排得越靠前——最近上线了什么可以看更新日志。

常见问题

我的数据安全吗？

安全。每个工具都完全在你的浏览器中通过 JavaScript 运行，你处理的文件和文本都在你的设备上完成处理，绝不会上传到任何地方。你可以自己验证：在使用任意工具时打开浏览器的网络（Network）面板，你不会看到文件离开你的设备。

norito 为什么是免费的？

广告（通过 Google AdSense）覆盖了托管成本。没有付费版本，也没有计划将任何工具设为付费。

你们会保存或查看我的文件吗？

不会。这些工具背后没有任何服务器组件，所以我们这边没有任何途径可以保存、记录甚至查看你上传的内容。

关闭标签页后会发生什么？

一切都会消失。除了保存在浏览器本地存储中的少量界面偏好设置（例如你上次使用的输出格式）外，不会保留任何内容，而这些设置同样不会离开你的设备。

你们使用 Cookie 吗？

norito 自身的代码不使用 Cookie。Google AdSense 可能会设置广告相关的 Cookie，详情见隐私政策。
